Privacy Policy / Datenschutzerklärung

English

Plush Physics is a private automation used only by the owner of the Plush Physics YouTube channel. It uses the YouTube Data API solely to upload videos that it has rendered itself to the owner's own channel.

It does not collect, store, share or sell any data about other people. The only Google data it accesses is the permission to upload videos to the owner's channel. The access token is stored encrypted as a GitHub Actions secret and can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deutsch

Plush Physics ist eine private Automatik, die nur vom Inhaber des YouTube-Kanals „Plush Physics“ genutzt wird. Sie verwendet die YouTube Data API ausschließlich, um selbst erzeugte Videos auf den eigenen Kanal hochzuladen. Es werden keine Daten anderer Personen erhoben, gespeichert, weitergegeben oder verkauft. Der Zugang ist verschlüsselt gespeichert und kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
